## 一、这个功能解决什么问题

判断「今天市场好不好做」，靠单一指标都会失真：指数涨了可能只是权重股拉的，涨停多可能只是游资在炒一只票，成交额大可能是恐慌抛售。

所以这里把情绪拆成 **七个可解释的维度**，各自打 0~100 分，加权成一个「市场温度」，再映射成五档天气。每一维都能单独说清「为什么是这个分」。

| 维度 | 权重 | 回答什么问题 | 数据口径 |
|---|---|---|---|
| 涨跌广度 | 20% | 多少股票在涨 | 全 A 涨跌家数 + 涨跌幅中位数 |
| 打板强度 | 16% | 短线资金敢不敢打 | 涨停/跌停比 40% + 封板率 30% + 连板高度 30% |
| 资金流向 | 20% | 真金白银往哪走 | 主力净流入占成交额 72% + 融资净买入占余额 28% |
| 量能热度 | 10% | 参与热度 | 成交量 / 20 日均量（按交易时段折算） |
| 结构扩散 | 12% | 普涨还是独苗 | 上涨行业占比 + 行业涨幅中位 |
| 波动恐慌 | 10% | 恐慌程度（反向） | 20 日波动率 / 60 日基准 |
| **全网讨论** | **12%** | **散户在聊什么** | 股吧人气榜赚钱效应 60% + 论坛帖多空比 40% |

**五档天气**：☀️晴（≥72）｜⛅多云（58~72）｜☁️阴（45~58）｜🌧️小雨（32~45）｜⛈️暴雨（<32）

**极端提示**：温度 ≥85 或（上涨占比 ≥85% 且涨停 ≥60 家）→ 亢奋；温度 ≤15 或上涨占比 ≤10% → 冰点；炸板率 >45% 且涨停 ≥20 家 → 分歧加大。

## 四、算法说明

### 4.1 单维打分（各 0~100）

**广度** = 100·[0.5 + 0.5·tanh(2.2·(r_up − 0.5))] + 8·tanh(m / 1.2)
　　r_up = 上涨占比，m = 涨跌幅中位数（%）

**强度** = 100·(0.4·L_up/(L_up+L_down+1) + 0.3·(1 − B/(L_up+B+1)) + 0.3·min(H/6, 1))
　　L = 涨停/跌停家数，B = 炸板家数，H = 最高连板

**资金** = 0.72·clamp(50 + 50·(M/A)/0.03) + 0.28·clamp(50 + 50·(N_m/R_m)/0.02)
　　M = 主力净流入，A = 沪市成交额，N_m = 融资净买入，R_m = 融资余额

**量能** = clamp(50 + 50·tanh(0.9·(ρ − 1)))，ρ = 今日成交量 / (20 日均量 × 时段进度)

**结构** = 100·[0.5 + 0.5·tanh(2.6·(q − 0.5))] + 10·tanh(m_ind / 0.8)
　　q = 上涨行业占比，m_ind = 行业涨幅中位

**波动** = clamp(50 − 45·(σ20/σ60 − 1))　（反向计分）

**讨论** = 0.6·人气榜赚钱效应 + 0.4·论坛帖多空分
　　人气榜 = 100·(0.55·TOP30 上涨占比 + 0.45·(0.5 + 0.5·tanh(平均涨幅/2.5)))
　　论坛帖 = 0.6·条数口径 + 0.4·热度口径（热度 = 阅读 + 评论×20）

### 4.2 合成

```
T = Σ wᵢsᵢ / Σ wᵢ     w = (0.20, 0.16, 0.20, 0.10, 0.12, 0.10, 0.12)
```

**某维不可用时从分母剔除并重新归一，绝不补 50 分**——补中性会凭空把温度拉回中间。

### 4.3 标题词典

- 强词 ±2（涨停/跌停/暴涨/腰斩/获批/立案…），弱词 ±1（上涨/下跌/加仓/减持/中标/停产…）
- 前置 3 字内出现否定词（不/没/别/勿/未/难/无）→ 极性翻转
- **资讯型标题记中性**：命中「复盘/早评/公告/研报/龙虎榜/三大指数/沪指/两市」等，只陈述事实不计多空
- 同一标题多股吧转发 → 按标题去重

## 四点五、情绪结构分析（从「一个数」到「有结构的判断」）

多空比是一个标量，它回答不了三个关键问题：**为什么**看多、**算高还是低**、**一致还是分歧**。
这一层专门补这三个问题。

### 4.5.1 归因：按主题拆解

每条内容（论坛帖 + 快讯）按**关键词优先级**归到一个主主题，优先级从「具体」到「泛化」：

```
个股事件 → 政策监管 → 业绩财报 → 资金面 → 行业景气 → 题材概念 → 技术面 → 宏观外围 → 短线打板 → 闲聊无主题
```

| 主题 | 典型触发词 |
|---|---|
| 个股事件 | 减持/增持/回购/重组/立案/解禁/中标/获批 |
| 政策监管 | 政策/证监会/央行/降准/降息/国常会/补贴 |
| 业绩财报 | 净利/营收/预告/扭亏/预增/毛利率 |
| 资金面 | 北向/主力/融资/ETF/净流入/持仓/两融 |
| 行业景气 | 涨价/订单/产能/库存/满产/扩产 + 行业名 |
| 题材概念 | AI/算力/机器人/固态电池/低空/稀土 |
| 技术面 | 均线/突破/支撑/放量/背离/回踩 |
| 宏观外围 | 美联储/汇率/关税/地缘/恒生/纳指 |
| 短线打板 | 连板/首板/炸板/龙头/接力/退潮 |

**优先级里有两个坑**（都是被测试逼出来的）：
- 「需求/供给/景气」太泛，会把「AI 算力需求爆发」抢到行业类 → 删掉；
- 「资金」太泛，会把「接力资金退潮」抢到资金面 → 删掉。

### 4.5.2 阈值：多空比分档

| 区间 | 档位 | 含义 |
|---|---|---|
| 0~25% | 极度悲观 | 几乎只有看空声音，常见于恐慌杀跌末端 |
| 25~45% | 偏空 | 看空占优，但仍有分歧 |
| 45~55% | 多空分歧 | 多空力量接近，方向不明 |
| 55~75% | 偏多 | 看多占优，属于常态偏暖 |
| 75~100% | 极度乐观 | 看多占绝对多数，常见于题材高潮，需防一致性反转 |

**样本少于 20 条时整套阈值都不可靠**，页面会显式提示「仅作参考」。

### 4.5.3 阈值：情绪温度分档（绝对口径）

| 区间 | 档位 |
|---|---|
| 0~15 | 冰点 |
| 15~32 | 偏冷 |
| 32~45 | 偏弱 |
| 45~58 | 常态 |
| 58~72 | 偏热 |
| 72~85 | 过热 |
| 85~100 | 异常高涨 |

**为什么不用历史分位**：能拿到的长序列只有「量价近似温度」（由指数 K 线派生），它的刻度与七维综合分不是一回事（综合分还含资金/讨论/打板）。拿近似序列的分位去衡量综合分，会得出「100% 分位 = 异常高涨」这种看起来精确、其实口径错配的结论。**宁可给一个说明白的绝对阈值，也不要给一个假装精确的分位数。**

### 4.5.4 结构指标

| 指标 | 定义 | 怎么读 |
|---|---|---|
| **分歧度** | 100 × (1 − \|2r−1\|)，r = 多空比 | ≥60 尖锐对立（变盘前）；≤25 极端一致（警惕反转） |
| **一致性** | 100 − 分歧度 | — |
| **主题集中度** | TOP1 主题 / 有主题内容数 | 越高说明讨论越聚焦，越低说明东一榔头西一棒 |
| **信息含量** | 1 − 闲聊占比 | 实测约 40%：大部分发言是实盘打卡和情绪宣泄 |
| **消息面背离** | 快讯多空比 − 论坛多空比（pp） | >+20 利好没被散户认可（预期差）；<−20 散户跑在消息前面（透支） |
| **量价背离** | 讨论量 vs 指数涨跌 | 热且跌 = 顶部特征；冷且涨 = 底部特征 |

### 4.5.5 个股抽取

对标题做 3~6 字滑窗，匹配全 A 股票名索引（5576 只）。

**必须配一份通用词黑名单**：`机器人`、`中国`、`东方`、`上海`、`黄金`、`芯片`、`算力`…… 这些既是股票简称，也是题材/地域词。不过滤的话「机器人板块爆发」会命中 300024（新松机器人），个股榜会被噪声刷满。宁可漏掉几只，也不要满屏误报。

另外只保留**提及 ≥2 次**的个股，单次命中多半是误匹配。

### 4.5.6 自动结论

把上面的指标翻译成人话，6~7 条：

> 带方向样本 31 条，看多占比 77%，落在「极度乐观」区间——看多占绝对多数，常见于题材高潮，需防一致性反转。
> 看多主要集中在 短线打板(7)、政策监管(4)、宏观外围(3)、题材概念(3)；看空集中在 宏观外围(2)、技术面(1)、业绩财报(1)。
> 分歧度 45，仍有明显分歧，但方向已偏向一方。
> 讨论的信息含量只有 40%，其余是实盘打卡、喊单和情绪宣泄——这类内容方向性最纯粹，但也最容易被带节奏。
> 综合温度落在「58~72 偏热」区间（偏热）。
> 被提及最多的个股是大业股份(4 次)、青岛食品(3 次)、光洋股份(2 次)。

## 四点六、消息面重点区分（从「40 条平铺」到「5 条焦点」）

### 4.6.1 问题

财联社电报本身不缺数据，缺的是**取舍**。原来 40 条按时间倒序平铺，一条「央行降准」和一条「某公司中标 300 万」长得一模一样，只有 A 级挂了个小「重要」标签，读者得自己从 40 条里挑重点。

### 4.6.2 影响力打分（0~100，规则可解释）

| 维度 | 加分 | 说明 |
|---|---|---|
| 官方重要度 | A 42 / B 26 / C 14 | 财联社 level 字段 |
| 政策级 | +26 | 央行、证监会、国常会、降准、降息、LPR、印花税、平准基金… |
| 实质事件 | +12 | 获批、中标、立案、减持、停产、涨价、预披露… |
| 金额体量 | +6 / +14 / +18 | 1 亿 / 10 亿 / 100 亿以上，**必须挂在事件动词上** |
| 阅读量 | +3 / +6 / +10 | 1 万 / 5 万 / 10 万以上 |
| 覆盖板块 | +4 | subjects ≥ 2 |
| 表态型降权 | −8 | 「看好/建议关注/预计」且无实质事件 |

分档：≥72 **S**（改变当天主线）、≥52 **A**（有主体的实质消息）、≥32 **B**（局部影响）、其余 **C**。

三个降权口子都是实测踩出来的：

- **例行播报**（指数播报、融资余额、收盘统计）压到 C 档，权重 0.25；
- **合集型**（早间精选、投资日历、盘前速览）打 **0.55 折**且**不计多空**——它天然包含一堆政策词和金额，不折会直接冲到 96 分占满焦点；
- **金额只在有事件动词时才算体量**，「投资日历」里的「北向资金 4120 亿」是背景数据，不是事件规模。

### 4.6.3 主题分布

消息面用一套比论坛更「新闻体裁」的规则：政策监管 → 宏观外围 → 业绩财报 → 个股事件 → 行业景气 → 题材概念 → 资金面，未命中归「未归类」。每个主题统计条数、影响力合计、影响力占比、多空构成，点击可筛选。

> 实测：第一版未归类 8 条（KOSPI/台交所/A50 期货/地震/迪士尼裁员），补规则后降到 2 条。

### 4.6.4 加权多空比

条数比是「一条算一票」，会被 30 条中性小公告稀释。所以同时给**影响力加权多空比**（权重 = 1 + 影响力/40，例行 0.25、合集 0.4）。

两者差距 ≥8pp 时自动解释：

> 条数多空比 46%，按影响力加权只有 24%（−22pp）：利空集中在重磅消息里，小消息偏多，别被条数骗了。

主题内部的方向也走加权口径——否则「8 条里 3 条利好 2 条利空」会说偏多，而真正主导的那条是利空。

### 4.6.5 政策方向兜底

「央行降准 0.5 个百分点」这句话里没有任何多空词，情绪词典只会记中性。所以政策类单独判方向：

- 宽松：降准、降息、下调准备金率/LPR、净投放、再贷款、补贴、减税…
- 收紧：上调准备金率/LPR、加息、净回笼、正回购、去杠杆…

> 实测踩坑：`上调.{0,6}准备金率` 匹配不到「上调金融机构外汇存款准备金率」（中间隔了 6 个字），窗口放宽到 14 字才命中。

### 4.6.6 界面

1. **自动结论**（5 条）：重点集中度、条数比 vs 加权比、主导主题、最重的 S 级、噪声说明；
2. **今日焦点**：S/A 优先，不足用 ≥40 分的 B 级补位，最多 6 条；合集、例行、未归类永不入选；
3. **主题分布**：条形=影响力占比，右侧红绿=多空条数；
4. **筛选**：只看重点 / 全部 / 利好 / 利空 / 例行播报 + 主题叠加；
5. 列表默认只显示**标题**（财联社【】里的小标题），完整正文在悬停提示里。

## 五、关键工程问题与解法（踩坑清单）

### 1. 东财 push2 会整体限流

并发 8 拉 56 页全市场行情后，整个 `push2.eastmoney.com` 域（含指数、资金流）返回 500 或断连，恢复要几分钟。
**解法**：大批量数据改由新浪承担，push2 只剩 0~1 个请求。

### 2. 盘中量能不能直接比全天均额

A 股日内成交额是 U 型的（开盘 30 分钟约占 20%）。10 点拿成交额除「20 日全天均额」永远是「0.4 倍缩量」。
**解法**：按 U 型累积曲线内插折算，指标卡标注「按 36% 时段折算」。

### 3. 北向净买入已停披

2024-08 起 `NET_DEAL_AMT` 恒为 null。**解法**：只展示成交额活跃度，明确不参与打分。

### 4. 季报 vs 半年报口径（沿用机构持仓页结论）

基金在 Q1/Q3 只披露前十大重仓，Q2/Q4 披露全量。跨类型比较会得出假涨跌。

### 5. React StrictMode 让请求翻倍

开发模式下 effect 跑两次，60 多个请求打两遍。**解法**：模块级 in-flight promise 复用。

### 6. 无 CORS 域名不该直连

新浪/push2his/datacenter 都不发 `Access-Control-Allow-Origin`，直连会挂起超时，把首屏从 8s 拖到 22s。
**解法**：`allowDirect` 只对带 CORS 的域名开启。

### 7. ECharts 的 gauge 色带是比例不是分值

`axisLine.lineStyle.color` 要 `[0~1, color]`，直接写 32/45/58 会被当成 1，整条弧线同色。

### 8. ECharts 类目轴默认第一项在最下方

排行榜类横向条要加 `inverse: true` 才是「第一名在上」。

### 9. `tooltipBase()` 是 axis 触发

柱状图直接用会让 formatter 收到**数组**，`p.name/p.value` 全是 undefined。分箱图必须 `trigger: 'item'`。

### 10. 饼图不认 `data[].color`

必须映射成 `itemStyle.color`，否则一直用默认色板（多空比环图曾因此把「看多」画成蓝色）。

### 11. 股吧会触发「身份核实」验证码

PC 页高频抓取后返回 2.8KB 验证页。**解法**：双通道，PC 被拦自动降级移动端（`mguba`，只有标题无阅读数），并用模块级标记避免重复重试。

### 12. 淘股吧必须带 Referer

不带直接 502，而浏览器 `fetch` 不允许设 Referer。**解法**：在代理层注入（vite `headers` / server.mjs REFERER map）。

### 13. 财联社需要签名，且 Web Crypto 没有 MD5

`sign = md5(sha1(排序后的 query))`。`crypto.subtle` 只提供 SHA-1，**不提供 MD5**。
**解法**：自带一份紧凑 MD5 实现，用标准向量（空串/abc/fox）做单测。

### 14. 主题关键词太泛会互相抢

「需求」把「AI 算力需求」抢到行业类，「资金」把「接力资金退潮」抢到资金面。
**解法**：删掉过于泛化的词，只保留有区分度的；并写测试锁住优先级。

### 15. 个股名匹配需要通用词黑名单

「机器人」「中国」「东方」「黄金」既是股票简称也是题材/地域词，不过滤会把个股榜刷成噪声。

### 16. 资讯型标题会污染多空比

淘股吧大量「11.2复盘：今日涨停 80 家」，涨停是陈述事实。不过滤时多空比 89%（失真）。
**解法**：资讯型标题记中性；但过滤词不能太宽（试过把「题材/数据/开盘」也加进去，中性占比飙到 87%，误杀正常观点帖）。

## 六、已知局限（诚实清单）

| 局限 | 说明 |
|---|---|
| **讨论样本偏小** | 单日有效多空样本常只有 15~20 条，多空比波动大。页面已提示「样本少于 20 条」 |
| **词典读不懂反讽** | 「又要跌停了吧」「不会跌停」这类靠否定词勉强处理，谐音/多义词无解 |
| **一条快讯可能多方向** | 「指数收涨但黄金股领跌」只能标一个方向 |
| **主力资金流不可用** | 本机 `push2his` 整域不通，已降级为「融资净买入」并给重试按钮 |
| **讨论只覆盖股吧+淘股吧** | 雪球被 WAF 拦、微博需登录、抖音需强签名 |
| **历史温度是近似值** | 历史涨跌家数/资金流拿不到长序列，曲线只用指数量价派生，绝对值不可与当日分直接比 |
| **行业口径 49 个** | 新浪行业分类，比东财二级（116 个）粗 |
| **主题分类是关键词规则** | 一条内容只归一个主主题，跨主题的复杂讨论会被简化 |
| **信息含量约 40%** | 六成发言是实盘打卡/情绪宣泄，这是 A 股论坛的真实分布，不是抽取失败 |

### 第一层：可直接做（无登录、弱反爬）

|---|---|---|---|
| 淘股吧 | `tgb.cn/zongban` | ★ | ✅ 已接入 |

| 韭研公社 | `jiuyangongshe.com` | ★★★ | 未做（本机不可达） |

### 第二层：需登录态 / 签名逆向（能做但脆）

| 平台 | 障碍 | 建议 |
|---|---|---|
| 雪球 | WAF 挑战页（`renderData` 加密），需 `xq_a_token` | 无头浏览器过 WAF 后复用 cookie |
| 微博 | 搜索需登录 cookie + `XSRF-TOKEN` | 走**微博开放平台**（有免费额度） |
| 抖音 | `X-Bogus`/`a_bogus` 签名 + 设备指纹 + 滑块 | **强逆向，建议买数据**（蝉妈妈/飞瓜） |
| 小红书 | 签名 + 极严风控，个人号易封 | 买数据（千瓜/新红） |
| 知乎 | 登录墙 | 开放平台或镜像 |

### 第三层：不建议自建

抖音 / 快手 / 小红书 / B站：强签名 + 行为风控，逆向随时失效，且违反平台 ToS。
微信公众号：无公开检索，只能靠第三方（新榜）。
Twitter/X：API 收费昂贵（$100/月起）。
Reddit：有官方 API，但**本机网络不可达**（http=000）。

### 合规红线

1. 只抓公开可见内容，不碰私信、不碰需登录才能看的内容
2. 不存储用户个人信息（昵称/ID/头像），只保留「标题 + 情绪标签 + 聚合计数」
3. 遵守 `robots.txt`，控制频率（股吧验证码就是频率过高的结果）
4. **商用必须获得授权**——《数据安全法》《反不正当竞争法》均有判例

### 推荐路线

```
阶段 1（已完成）  股吧 + 淘股吧 + 人气榜 + 千股千评
阶段 2（已完成）  财联社快讯（消息面）
阶段 3（要花钱）  抖音/小红书/微博 → 买第三方数据 API，不要自建
```
